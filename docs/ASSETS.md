# Recursos visuales de AppNexo V1.4

## Estructura

- `assets/images/brand/` → logo, isotipo, favicon y Open Graph.
- `assets/images/services/` → imágenes de servicios.
- `assets/images/projects/` → capturas reales de sistemas.
- `assets/images/products/` → portadas de productos digitales.
- `assets/images/youtube/` → miniaturas de videos o playlists.
- `assets/images/profile/` → fotografía profesional.
- `assets/images/backgrounds/` → fondos decorativos.
- `assets/icons/` → iconos propios.

## Tamaños sugeridos
- Logo horizontal: SVG preferentemente.
- Open Graph: 1200 × 630 px.
- Proyecto: 1600 × 1000 px o proporción similar.
- Producto: 1200 × 750 px.
- YouTube: 1280 × 720 px.
- Perfil: 1200 × 1500 px.

Puedes usar `.webp`, `.png`, `.jpg` o `.svg`. Si cambias una extensión, actualiza el `src` correspondiente en el HTML.
